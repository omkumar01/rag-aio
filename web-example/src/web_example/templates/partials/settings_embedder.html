Embedding

The "mock" backend is a deterministic placeholder with no semantic similarity — chat retrieval cannot find relevant context with it. "fastembed" runs a local ONNX model (dimension must match your collection: bge-small = 384). "remote" calls any OpenAI-compatible /embeddings endpoint (LM Studio, Ollama, vLLM, OpenAI) — it requires an explicit model id and dimension because the vector store is sized before the first request. Changing the model or dimension switches to a new, empty collection: re-ingest your documents so they are searchable again.
