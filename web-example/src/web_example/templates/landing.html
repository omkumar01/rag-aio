rag-aio

From OCR to citations in one process — 18 composable Python packages, one facade.

rag-aio is a uv workspace monorepo of independently testable, independently deployable packages that compose into a full Retrieval-Augmented Generation pipeline — document ingestion and OCR, chunking, embedding, hybrid retrieval, reranking, context engineering, and provider-agnostic LLM generation — with observability, caching, evaluation and bulk ingestion built in. Everything ships in a single wheel; the offline mock profile runs the quickstart with zero services and zero API keys.

What it does

Every I/O interface is async — ingestion, retrieval and generation are built for concurrency from the ground up.

Fully async pipeline

Every I/O boundary is an async Protocol: loaders, stores, embedders, retrievers and providers compose with bounded queues and per-stage concurrency.

Hybrid retrieval

Dense, sparse and BM25 retrieval fused with RRF or weighted scoring, then reranked by heuristic or cross-encoder models.

OCR with VLM escalation

Fast mechanical OCR first; low-confidence pages escalate automatically to a vision-language model for a second pass.

Mass ingestion with checkpoints

High-throughput bulk loading with per-stage concurrency, checkpoints, resume and dead-letter handling for slow onboarding of large corpora.

Secrets by reference

Configuration stores env-var names, never secret values; secrets stay redacted in logs, traces and the UI.

Streaming chat with citations

Token-budgeted context building with citation provenance, streamed token-by-token from OpenAI/Anthropic/Gemini/Ollama-compatible providers.

One pipeline, end to end

Documents flow through the stack in a single process — no glue code, no vendor lock-in.

Load & parse→ OCR→ Chunk & embed→ Index→ Hybrid retrieve→ Rerank→ Build context→ Generate & cite

The package catalogue

Every package is independently testable and deployable; the rag-aio facade pulls them together behind one RAG class and one CLI.

Memory, disk and sqlite cache backends with TTLs and usage stats.

Qdrant vector store plus SQL document/KV stores via async SQLAlchemy.

Ingestion & enrichment

4 packages

Loaders and parsers (PDF, Office, HTML, EML and more), the ingestion pipeline, and web crawlers.

Hybrid mechanical OCR with confidence-driven escalation to a vision-language model.

rag-embedder

Chunking strategies, dense and sparse embedding, and the indexing pipeline.

rag-mass-inject

High-throughput bulk ingestion with bounded queues, checkpoints, resume and dead letters.
