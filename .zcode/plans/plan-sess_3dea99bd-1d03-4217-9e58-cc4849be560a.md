## Key implementation decisions
- Protocols (`typing.Protocol`, runtime-checkable) as contracts; adapters registered via entry points + explicit registries. No vendor types in rag-core.
- Qdrant via `qdrant-client` **local mode** by default (persistent path, zero infra); server mode = config change only; `docker-compose.qdrant.yml` provided.
- LM Studio-first: `rag-generation`'s OpenAI-compatible adapter is the reference adapter, pointed at localhost:1234; reranker + glm-ocr semantic path + embeddings exercised through it in e2e (skippable tests auto-skip when endpoint unreachable).
- Heavy deps strictly optional: torch/sentence-transformers, docling, faiss-cpu, redis, psycopg — extras only; FastEmbed default embedding; BM25 sparse via FastEmbed/bm25s.
- CPU/GPU inference (OCR, embeddings, reranking) runs via `asyncio.to_thread`/process pools off the event loop; all I/O async; bounded queues/semaphores everywhere.
- Untrusted-content isolation: system prompts separated from document text with delimiters + sanitization; SSRF guard for crawler; upload/size/page/token limits; secret masking in logs/UI/API.
- Metrics implemented in-house (no heavy ranx) to keep eval light.
